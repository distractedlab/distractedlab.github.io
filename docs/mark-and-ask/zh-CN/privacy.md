# 隐私政策 · Mark & Ask

Mark & Ask (by DistractedLab) · 生效日期：2026-11-25

## 概述

本政策说明 Mark & Ask 0.4.0。Mark & Ask 是本地优先的浏览器扩展：没有账号系统，也没有 DistractedLab 运营的服务器。笔记和设置保存在你的浏览器里。本页说明例外情况、涉及的数据，以及如何删除这些数据。

## 扩展保存在本机的数据

扩展为了提供标记、整页备注、阅读状态、笔记列表和导出功能，会把以下数据保存在你的设备上：

- 网页记录：地址、规范化地址、域名、标题、阅读状态、创建和更新时间。
- 标记：选中的文字及定位所需的上下文与字符位置，或图片地址、描述和定位所需的上下文。还保存标记样式、批注和创建时间。本机记录上次共同定位的顺序与观察时间，备份不包含该记录。
- 整页备注。
- 设置：界面语言、标记显示与主题、排序与筛选、AI 服务地址、模型与上下文预算、对话角色、Markdown 方案，以及 Vault 目录授权。

## 保存位置与本机数据

存储位置：IndexedDB 保存网页记录、整页备注和标记，另有本地数据库保存 AI 服务地址、模型、加密后的 API Key 和 Vault 目录句柄；chrome.storage.local 保存上面列出的设置；chrome.storage.session 只保存当前批注焦点，关闭浏览器后清空。

扩展只把这些数据用于上述功能。扩展不做云同步，也不包含统计、广告或遥测代码。

本机记录没有额外加密，能访问你浏览器配置文件或电脑的人可以读取它们。API Key 的处理方式见下文。

## 扩展读取的内容

- 打开侧栏时，扩展读取当前标签页的地址和标题，用来匹配已保存的记录。它不会读取浏览历史或其他标签页。
- 为了显示已保存的标记，扩展会读取当前网页的文字和结构。这些读取只在本机进行。
- 当你标记文字、划词提问、附页或生成 Markdown 时，扩展会读取选区或网页正文。

## 离开浏览器的内容

扩展自身只会把数据发送给你配置的 AI 服务。除此之外，只有当你主动打开并提交反馈表单时，数据才会离开浏览器；该表单是 Tally 托管的普通网页。你访问的网站、你的 AI 服务商和 Tally 各有自己的隐私政策。

对话、划词提问、附页对话和生成 Markdown 使用同一个已保存的 AI 服务。测试连接或保存新的服务及 API Key 时，扩展会请求模型列表，验证请求不会包含网页内容。远程服务使用 HTTPS，本机回环服务可以使用 HTTP。请求拒绝重定向，不携带 Cookie，也不发送 Referer。响应超过 2 MB 时停止读取。

你的 AI 服务商（可能是中转站）会收到请求内容和 IP 地址等常规网络信息，并按其自身条款和隐私政策处理。DistractedLab 不运营该服务，也收不到这些请求。

请求包含所选方案或指令，以及按操作不同而定的以下内容：

- 对话：你的问题和预算内最近最多 6 条历史消息。附页时还包括网页标题和预览中列出的相关正文片段。
- 划词提问：点击按钮时发送网页标题、解释指令、选中文字（最多提取 12,000 字符）及少量邻近上下文。聊天草稿和附加的网页正文留在输入区。
- 总结本页笔记与标注：页面标题、预算内的标记类型（高光、下划线或独立批注）和原文、相应批注及整页备注。当前网页 Markdown 使用按阅读顺序定位的标记。你可以单独选择发送历史回顾，将当前未定位的引文、批注和已知的相对顺序或顺序未知说明发给 AI。此选项每次默认关闭。
- 本页摘要和结构化网页笔记：页面标题和按章节选取的正文。预览标明提取和请求预算造成的省略。

## 不会发送的内容

不会发送：网页地址、标记颜色、下划线形状、定位偏移、图片、其他网页的记录，也不会把 API Key 放进正文。Key 只出现在 Authorization 请求头中。聊天记录只在内存中保留于当前侧栏会话，关闭侧栏后即丢失。

## 反馈表单

「关于」里的反馈入口会按界面语言，在新标签页打开 Tally 表单。扩展不会预填或传输你的笔记、网页地址、浏览历史或 API Key。Tally 会收到你填写并提交的内容，以及 IP 地址等常规网络信息，并按 [Tally 的隐私政策](https://tally.so/help/privacy-policy)处理。提交内容会被阅读，用于回复问题和改进产品。请不要提交 API Key、密码或其他机密信息。

## API Key

- Key 以 AES-256-GCM 加密后保存在扩展的本地数据库。解密用的密钥与密文存放在同一数据库里，因此明文不会出现在备份、导出或普通存储读取中；但这不能抵御能访问你浏览器配置文件或系统账户的人。
- Key 只通过 HTTPS 发送给你配置的 AI 服务商，放在 Authorization 请求头中。
- Key 不进入备份。
- 卸载扩展或丢失本地数据后，Key 无法找回。从本机移除 Key 不会撤销它；设备遗失或怀疑泄露时，请到服务商后台撤销。

## 保存时间与删除方式

由于记录只保存在浏览器里，DistractedLab 无法访问这些记录，也无法替你读取、导出或删除。反馈提交由 Tally 保存；相关问题请使用[反馈表单](https://tally.so/r/aO2PQE)提出。

- 本机记录会保留到你删除它们、清除浏览器数据或卸载扩展为止。
- 你可以在笔记列表查看记录，并在「备份与恢复」中导出 JSON。
- 在笔记列表里删除网页及其标记、备注，或在 AI 服务设置里移除 Key。
- 卸载扩展会删除本地记录、设置和 Key；撤销站点访问权限会停止标记与高亮恢复。
- 聊天记录只在内存中，关闭侧栏后消失。
- 备份、Markdown 文件和 Vault 目录里的文件在扩展之外，会一直保留到你自行删除。

## 权限用途

- activeTab、scripting：在你当前查看的网页上添加和恢复标记。
- tabs：读取当前标签页的标题和地址，用于匹配记录。
- storage：保存本地记录与设置。
- sidePanel、contextMenus：显示侧栏和右键菜单。
- `file:///*`：仅在你于 Chrome 扩展详情中开启「允许访问文件网址」后，读取本地 HTML 文件以添加标记；文件地址会保存在本机记录中。
- 可选权限：访问你填写的 AI 服务域名，以及下载导出文件；两者都在使用时才申请。
